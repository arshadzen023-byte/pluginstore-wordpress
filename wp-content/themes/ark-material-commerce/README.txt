ARK MATERIAL COMMERCE — INSTALLATION
====================================

This is a lightweight WordPress theme with Material Symbols icons, responsive layouts,
WooCommerce support and mobile bottom navigation.

INSTALL
1. WordPress Admin → Appearance → Themes → Add New Theme → Upload Theme.
2. Upload ark-material-commerce.zip and click Install Now → Activate.
3. Install WooCommerce for shop/product/cart/checkout/account pages.
4. Install Elementor (free) to drag-edit page content.
5. Elementor Pro is optional. It enables Theme Builder for custom Header/Footer,
   product templates, archive templates, popups and additional dynamic widgets.
6. Go to Appearance → Customize → ARK Header & Footer to edit the brand name,
   header search, mobile navigation toggle and footer copyright text.
7. Go to Appearance → Menus to assign Primary Menu and Footer Menu.
8. Set your homepage at Settings → Reading. Edit the page with Elementor.

ELEMENTOR NOTES
- Elementor can edit the content of pages and posts. Use Elementor's page settings
  to select Elementor Full Width or Elementor Canvas where available.
- If Elementor Pro Theme Builder is installed, create Header and Footer templates
  and set Display Conditions to Entire Site. This theme registers Elementor's core
  theme locations so the custom templates can replace the fallback theme header/footer.
- WooCommerce product, shop archive, cart, checkout and account functionality comes
  from WooCommerce. Elementor Pro's WooCommerce widgets/templates may be used when
  available in your Elementor Pro version.
- A theme cannot itself provide all third-party plugin features. Compatibility depends
  on each plugin and its own implementation. Test payment, shipping, cache and security
  plugins on staging before going live.

LIGHTWEIGHT / PERFORMANCE
- Minimal theme JavaScript; no bundled slider or page-builder framework.
- Material Symbols is loaded from Google Fonts. For fully local font delivery, download
  the font and enqueue it locally.
- For a production shop, configure image compression, caching, backups, HTTPS, security,
  and a supported payment gateway.

SECURITY
- This theme does not include or modify Elementor Pro plugin files. Install plugins only
  from their official source and keep WordPress, WooCommerce and plugins updated.
